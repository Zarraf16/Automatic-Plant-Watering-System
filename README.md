# Automatic Plant-Watering System

**Arduino · Soil-moisture sensing · Relay-controlled pump**

An individual embedded-systems project by **Zarraf Alam Fahmid**, combining soil-moisture sensing with automated water delivery.

## System overview

The Arduino reads a soil-moisture sensor and controls a water pump through a relay, allowing watering to respond to the soil condition.

| Subsystem | Purpose |
|---|---|
| Arduino | Read sensor input and control watering |
| Soil-moisture sensor | Detect soil condition |
| Relay interface | Switch pump operation |
| Water pump | Deliver water to the plant |

## Engineering focus

Sensor integration, relay interfacing, pump control, circuit assembly, and embedded control logic.
